## Assumptions and Open Questions

- DEC-01 to DEC-11 are the current MVP baseline and require stakeholder sign-off before automation is finalized.
- Use a dedicated test SQLite database, deterministic seed/reset, synthetic customer data, and a unique session ID per test.
- Use product fixtures with stock 0, 1, and N; do not depend on the shared development database.
- API errors follow `{ error: { code, message, fields? } }` and the status-code contract in DEC-07.
- Localization and multi-currency are out of scope for MVP; coverage is N/A because ASM-02 defines one consistent currency and locale.
- Test cases are designed but have not been executed.
